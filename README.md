# Proyectoinformatico2
tutorial para abrirlo conectando con la base de datossss
1-descargar la carpeta en .zip
2-poner "extraer aqui"
3-abrir la carpeta y copiar la carpeta "theclothesclub2"
4-cambiar el nombre a solo "theclothesclub"
5-tocar WINDOWS+R y copiar en C:\xampp\htdocs
6-poner la carpeta "theclothesclub" en esta ubicacion
7-crear una database en xampp llamada theclothesclub y agregar el insert de el documento "codigodeBD"
(para que funcione deben cumplirse todos los pasos anteriores y el xampp debe estar iniciado con la bd)
8-abrir la pagina desde el link 
http://localhost/theclothesclub/index.html
